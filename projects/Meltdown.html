Meltdown

Role: Gameplay Programmer
& Level Design  ·  Tech: C++, Unreal Engine 5  ·  Team Size: 1

[Gameplay GIF or High-Res Screenshot]

Overview

Meltdown is a Single-player puzzle game where you must solve audio puzzles to keep the reactor from going into meltdown, these puzzles include; Simon Says, Morse Code, and Find the Leak. Simon Says plays a sequence of audio cues that you must distinguish through spatialised audio only, Morse code makes you repeat a sequence of dots and dashes, and Find the Leak requires you to listen out for the machine making a sound. The main premise of this game is that it is an audio only game, and there is no visual aid to solve the puzzles. It is also the first game I developed in Unreal Engine.

Main Gameplay Mechanics

  • Simon Says puzzle; Spatialised audio that uses the Karplus Strong string synthesis as audio ques at different frequencies
  • Morse code player and recorder; Generates a sequence of dots and dashes to play, player has to repeat sequence by tapping or holding
  • Karplus Strong string synthesis (Synthetic Guitar Strings); Using white noise and audio processors to synthesise the sound of guitar strings at different frequencies and vibration length

Technical Challenges

Working in Unreal for pretty much the first time, I struggled quite a lot when it came to actually making things work. The whole idea of Blueprints to make something in the game work was the biggest challenge, especially with the fact that I'm so much more comfortable writing code like within Unity using C#.
